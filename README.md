# Website Portofolio – Sistem Informasi (Business Intelligence)

## Struktur
```
portfolio/
├── index.html   # konten
├── style.css    # tampilan
├── script.js    # interaksi
└── assets/      # taruh foto.jpg dan CV.pdf di sini
```

## Yang perlu diganti
Cari teks berikut di `index.html` lalu isi dengan data kamu:
- `Nama Lengkap Kamu`, `Nama.` (logo)
- `[X]`, `3.xx`, `20XX`, `[Jabatan]`, `[jumlah]`, `[Nama Acara]`, `[Nama Sertifikat]`
- `emailkamu@gmail.com` (juga ada di `script.js`), `username` LinkedIn/GitHub
- Link `href="#"` pada setiap proyek
- Persentase skill (`--w:85%`) dan angka statistik (`data-target`)
- Hapus proyek atau sertifikat yang tidak kamu punya. Jangan cantumkan yang tidak benar.

## Hosting gratis
- **GitHub Pages:** upload folder ini ke repo `username.github.io`
- **Netlify / Vercel:** drag & drop folder ini di netlify.com/drop
